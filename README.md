# yimiao-yu personal website

The personal academic website of Yimiao Yu (M.S. Data Science, NYU Center for Data Science). Built as a dependency-free static site using HTML, CSS, and JavaScript, featuring EB Garamond typography and automatic light/dark theme support. Site pages include About, Publications, CV, and Blog.

## Local preview

To preview the site locally, run:

```bash
python3 -m http.server
```

Then open http://localhost:8000 in your browser.
